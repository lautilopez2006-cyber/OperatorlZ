# OperatorlZ

Pantalla del DM para D&D: Mesa, combate, personajes, PNJ, mapas por planos y una wiki con monstruos, hechizos, especies, clases, dotes, reglas y manuales.

- `index.html` es la página que se publica.
- El código está en `src/`; después de editarlo, ejecutar `./build.sh` para regenerar `index.html`.
